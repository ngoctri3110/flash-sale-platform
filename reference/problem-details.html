API error contract

HTTPStable codeClient action
400VALIDATION_FAILEDShow fieldErrors; correct input
404PRODUCT_NOT_FOUNDRefresh or show resource unavailable
409INSUFFICIENT_STOCK / IDEMPOTENCY_KEY_REUSEDExplain business conflict; do not blindly retry with new key
500INTERNAL_ERRORShow safe message; send traceId to support

Every error uses application/problem+json, an RFC 9457 standard shape plus project extensions: code, traceId, and optional fieldErrors.
