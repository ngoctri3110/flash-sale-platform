Quick reference

Kubernetes operation checklist

  1. Build/load local images into Kind.
  2. kubectl apply -k k8s; wait rollout status.
  3. Readiness decides traffic; liveness restarts; startup gives JVM time to boot.
  4. Rolling update maxUnavailable: 0 retains current availability.
  5. Run in-cluster concurrency Job and verify accepted + rejected = attempts and stock never negative.

Requests reserve scheduling capacity; limits cap one container's resource consumption.
