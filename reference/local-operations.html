Quick reference

Local operations checklist

  1. docker compose up -d --build
  2. docker compose ps: backend must be healthy
  3. ./scripts/smoke-local.ps1: browse/order/inventory smoke
  4. GET /actuator/health/readiness: traffic readiness
  5. Use response X-Trace-Id to find matching logs.

Postgres/Kafka bind to localhost for local use; containers use service DNS.
