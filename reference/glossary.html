Shared vocabulary

Flash Sale backend glossary

TermMeaning in this project
Available QuantitySellable units in the single Inventory row for a Product; it must never become negative.
Atomic conditional decrementOne SQL update whose predicate checks sufficient stock while the update deducts it.
Idempotency-KeyClient key scoped to Customer; identical replay returns the existing Order without a second side effect.
Transaction boundaryThe `PlaceOrder.place()` unit in which inventory, Order and outbox intent commit or rollback together.
Outbox eventPersisted intent to publish `OrderCreated` after database commit; it is not a Kafka publish itself.
Optimistic conflictA version compare-and-swap update affects zero rows because another writer won first.
Pessimistic lockA database row lock acquired before business decision, commonly `SELECT ... FOR UPDATE`.

Use these exact terms in lesson answers and code review discussions.
