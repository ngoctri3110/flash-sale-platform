Review checklist

AI-generated backend code

  1. Contract: success/error HTTP shape and compatibility?
  2. Invariant: what must never be false; DB enforcement?
  3. Boundary: transaction starts/ends where; remote call inside?
  4. Side effects: DB, Kafka, log, retry; failure order?
  5. Concurrency: race, idempotency, lock scope, multiple replicas?
  6. Evidence: integration test proves observable outcome?
  7. Operations: migration, metric, trace, timeout, rollback?

Never approve code merely because it compiles, follows style, or has a plausible explanation.
