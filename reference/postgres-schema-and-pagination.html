Schema, index and pagination checklist

  1. Migration mới, không sửa migration đã chạy ở môi trường chia sẻ.
  2. DB constraint bảo vệ invariant; application validation cải thiện UX.
  3. Index theo query filter + order thực tế, không theo từng column riêng lẻ.
  4. Offset pagination cần bounded size và stable tie-breaker.
  5. Dùng EXPLAIN (ANALYZE, BUFFERS) trước khi kết luận index giúp.
