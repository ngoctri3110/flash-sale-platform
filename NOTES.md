# Teaching Notes

- Ngôn ngữ giảng dạy: tiếng Việt.
- Phương pháp: project-based, retrieval practice, test-first cho business logic rủi ro cao.
- Mỗi module cần có kiến thức, phần code xây dựng, bài tập kiểm tra hiểu và câu hỏi phỏng vấn.
- Với code do AI tạo: người học phải giải thích invariant, transaction boundary, failure modes và test chứng minh trước khi chấp nhận.
- Ưu tiên bài giảng tiếng Việt dễ hiểu: bắt đầu bằng ví dụ đời thường hoặc ví dụ code nhỏ, giải thích thuật ngữ English bằng nghĩa tiếng Việt, rồi mới liên hệ implementation của project. Lesson không chỉ liệt kê nội dung; phải giải thích từng bước và nêu khi nào dùng/không dùng.
- Chưa ghi learning record hay glossary term cho đến khi người học thể hiện được hiểu biết qua bài tập hoặc giải thích.
